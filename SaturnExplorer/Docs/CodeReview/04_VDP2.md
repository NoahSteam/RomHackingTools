# 04 — VDP2 / Pixel Mixer

## VDP2-01 — Medium — VDP1 priority model limits final compositor accuracy

The VDP2 pixel-column design is sound, but VDP1 enters the mixer with command-level priority. Mixed-priority VDP1 sprites therefore remain inaccurate even if NBG/RBG priority is decoded correctly.

See `03_VDP1.md`.

## VDP2-02 — Low — partial CRAM size relies on power-of-two masking

`CramColor` uses `index & (words - 1)`. Exact Saturn CRAM sizes make that valid; partial snapshot sizes do not.

## Positive

The compositor has strong targeted tests, and the reviewed baseline includes explicit plane-grid addressing coverage and a fix for tile-cache hash collapse.
