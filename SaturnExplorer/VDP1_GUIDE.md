# Saturn VDP1 — field guide

A plain-English tour of the Saturn's VDP1 drawing engine — the "everything is a four-cornered
quad" model, the command table, texture color modes, the VDP2-shared palette, Gouraud/draw
modes, the double frame buffer — and how Saturn Explorer's Command List, Selected Object,
Texture/Palette Viewers, VRAM Map, and 3D View let you inspect and extract it.
